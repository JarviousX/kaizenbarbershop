# Kaizen Barbershop

Premium static website for Kaizen Barbershop. React, Vite, and TypeScript. No backend. Booking buttons go to Squire.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static output is written to `dist/`.

## Deploy (Cloudflare, free)

```bash
npm run deploy
```

The live site is at [https://kaizen-barbershop.jackson24le.workers.dev](https://kaizen-barbershop.jackson24le.workers.dev).

Edit business details in `src/data/site.ts`. Search that file for `REPLACE` before launch.
